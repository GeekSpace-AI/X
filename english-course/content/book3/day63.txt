@diff: 「订单发出去了」——The order has been shipped.（东西做主语 → 被动）
@d_cn: 「订单发了」「货已经发出去了」「包裹被取走了」——东西做主语，中文常常连「被」字都不用。
@d_en: The order has been shipped. / The package is picked up from your warehouse. / Your customer is notified at every step.
@d_why: 中文里「订单发了」「标签生成了」，东西直接做主语，动词不变，很少用「被」——「被」字多用在倒霉事上（被偷了、被骂了）。英文不一样：订单自己不会「发货」，它是**被发出**的，所以东西做主语时要用**被动**：**be + 过去分词**。英文被动是中性的，没有「倒霉」的味道，讲流程、写通知、做报告到处都在用，因为我们关心的是订单和包裹，不是谁动的手。常见错误是漏掉 be 或用错分词：✗ The order has sent. ✗ The order is ship.。你在美国网店的自动通知里也会看到 Your order has shipped!——那是电商的固定说法；自己写邮件、跟客户解释时，用被动 has been shipped 最稳妥。
@d_when: 讲订单、包裹、文件、申请的状态；描述一个流程；写系统通知和工作邮件。
@d_vs: ✓ **The order has been shipped.** 订单已经发出了。\n✓ **The package is picked up from your warehouse.** 快递到你的仓库取件。\n✓ **Your customer is notified at every step.** 每一步顾客都会收到通知。\n✗ The order has sent. ／ ✗ The package is pick up.
@d_task: 用被动说：①「报告已经发给张涛了。」②「每个订单都会检查两遍。」 | ① The report has been sent to Tom. ② Every order is checked twice.
@diff: 被动的时态——时态变在 be 上：is / was / has been / will be
@d_cn: 「每次都会生成」「九点被取走的」「已经发出了」「周五会送到」——中文靠「会」「了」「已经」，动词本身不变。

@d_why: 被动 = **be + 过去分词**，过去分词（created、picked up、shipped）**永远不变**，时态全部体现在 **be** 上：每次都这样 → **is / are**；过去某个时间 → **was / were**；已经完成、结果还在 → **has / have been**；将来 → **will be**。第二册的老规则在被动里照样适用：有具体的过去时间（at nine、yesterday）就用过去时，不用完成时——Leo 说 The order has been shipped.
