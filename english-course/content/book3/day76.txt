@v: compensate | = | v. | ˈkɑːmpənseɪt | 赔偿；补偿（某人） | 说「赔给某人多少、赔什么」 | compensate sb for sth；compensate him in full；be compensated | We'll compensate you for the lost item. | 丢失的货品我们会赔给您。 | 结构是 compensate + 人 + for + 东西：✗ compensate the shoes to him → ✓ compensate him for the shoes；重音在第一个音节 COM-pen-sate，和名词 compensation 不一样。

@diff: 条件——as long as / if / unless
@d_cn: 讲规则离不开条件：「只要有货值证明，我们就受理」「如果买了保险，就能全额赔」「除非买了保险，否则最多赔 100 美元」。
@d_en: As long as you have proof of value, we'll process it. / If the package was insured, you'll get the full value. / Unless the package was insured, the maximum is one hundred dollars.
@d_why: 三个词对应三种语气。**as long as**（只要）强调「满足这一个条件就够了」，听起来是在**给对方希望**；**if**（如果）最中性；**unless**（除非）= if not，用来说**例外**：不满足这个条件，结果就是后面那句。中国学习者最常见的两个错：① 照搬「除非……否则……」写成 ✗ Unless the package was insured, otherwise the maximum is…——英文 unless 一个词就够了，不再加 otherwise；② 再加一个 not，变成双重否定：✗ Unless you don't file within thirty days…，意思全反了。时态上，这三个词后面说将来的事用**一般现在时**：As long as you **send** the invoice, we'll process it.（✗ will send）；而 Unless the package **was** insured 用过去时，因为寄件、买保险是已经发生的事。
@d_when: 解释退款、赔偿、退货、折扣的条件；给同事讲公司规定；谈合同条款。
@d_vs: **As long as you have proof of value, we'll process it.** 只要有货值证明，我们就受理。（给希望）\n**If the package was insured, you'll get the full value.** 如果寄件时买了保险，就能全额赔。（中性）\n**Unless the package was insured, the maximum is $100.** 除非买了保险，否则最多赔 100 美元。（说例外）\n✗ Unless…, otherwise… / ✗ Unless you don't file…
