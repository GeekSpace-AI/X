# 第四册编写计划（Day 91–120）

第四册的编写蓝图：每天的场景、中英差异点、指定新词、指定短语和锚点句。`build.py` 只读取 `day*.txt`，本文件不进入 PDF。

## 通用规则

- **新词不重复**：前三册已注释的词和短语（`python3 build.py check` 会自动比对）在第四册**不再注释**，只在新语境中自然复现。下表中每个词 / 短语只在指定的那一天注释。
- **锚点句**：每天 5 个锚点句必须**原样**出现在当天的【C】里。热身 6 句：前一天锚点 3 句 + 3–7 天前 1 句 + 第二册 1 句 + 第三册 1 句（重点复现第三册薄弱项：被动语态、percent / percentage point、邮件先说目的、拒绝给原因和替代方案、描述问题要具体）。
- **文本**：对话、会议记录、邮件混合；多人会议是第四册的主要形式。邮件句子不加说话人，前面用一句叙述交代。长度：D91–96 约 240–260 词；D98–103 约 250–270；D105–110 约 260–280；D112–119 约 270–300；复习日约 260–300。
- **听力**：第四册四步听法为「记笔记盲听 → 再听补笔记 → 看英文核对 → 段落听写」，全程不看中文；**【I】的前 2 题是听力题**（根据笔记回答谁说了什么、决定了什么）。
- **输出**：单数日 = 口头（会议发言 / 2 分钟汇报，录音）；双数日 = 书面（8–12 句的邮件）。都附示范。
- **时间线**：9 月初启动会 → 9 月 14 日试点开始 → 试点第一周出现状态错误（先用临时方案，再花两周做长期修复）→ 10 月中旬需求变更 → 10 月 28 日正式上线（赶在 11 月旺季之前）→ 一周后复盘 → 上线一个月后讨论加拿大扩展。
- **人物**：林晓 Lily（BrightNest 对接项目的项目协调人）、张涛 Tom、Emma（产品）、吴佳 Grace（客服）、李凯 Kevin（IT）、Mike（西雅图工程经理）、**Ana Ruiz**（西雅图测试工程师，新）、实习生 Leo；客户方 BrightNest：**Priya Nair**（运营经理）、**Raj Mehta**（IT 负责人，新）、**Karen Walker**（运营副总裁，新）；卖家 Sarah、Daniel 偶尔出现。
- **补充资源**（`@res`，可选）：只写「在 YouTube 频道 Rachel's English 内搜索 "……"」或「在 youglish.com 输入 "……"，选 US」，**不编造任何具体视频链接**。

## 每天的安排

### Day 91 · 用邮件提请求 / Making a Request by Email（第 1 周）
- 场景：林晓刚当上 BrightNest 项目的协调人，要请 Mike 的团队搭测试账号、请 Priya 提供样本数据；张涛帮她看语气。

- 短语（5）：would it be possible to, I'd appreciate it if, so that, by any chance, if that works for you
- 锚点句：Would it be possible to set up a test account by Thursday? ｜ I'd appreciate it if you could send us some sample data. ｜ We need it so that Mike's team can start testing. ｜ Do you have last month's order data by any chance? ｜ Let's aim for Friday, if that works for you.
