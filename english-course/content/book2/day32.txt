@diff: 「我吃过臭豆腐」——I've tried stinky tofu.
@d_cn: 说人生中有过某种经历（吃过、见过、试过），不说是哪一次。
@d_en: I've tried stinky tofu. / I've eaten it twice. / Have you ever tried it?
@d_why: 中文在动词后面加一个「过」，就表示「有过这种经历」。英文对应的是 **have + 过去分词**——第一册的 I've been to Beijing（D10）就是它，今天把 been to 换成任何动词：**I've tried / I've eaten / I've seen / I've met**。很多动词的过去分词和过去式不一样：eat → ate → **eaten**，see → saw → **seen**；try → tried → **tried** 是一样的。一旦说出具体的时间或那一次的场合（in Changsha、last year），就回到过去式：吴佳说 I tried it for the first time in Changsha.——她在讲「那一次」，所以用 tried。
@d_when: 聊经历、推荐食物和地方：I've tried it. / I've been there.；讲「那一次在哪儿、什么时候」：I tried it last year.。说句实话：美国人随口聊天时，有时也用过去式问经历（Did you ever try…?），听到不要奇怪；你自己说，用 have + 过去分词最稳。
@d_vs: **I've tried stinky tofu.** 我吃过臭豆腐。（经历）\n**I tried it in Changsha last year.** 我是去年在长沙吃的。（那一次）\n**I've eaten it twice.** 我吃过两次。\n✗ I've tried it last year. ✗ I have ate it.
@d_task: 用英文说：① 我吃过北京烤鸭（Peking duck）。② 我是 2020 年在北京吃的。③ 这部电影我看过两遍。 | ① I've tried Peking duck.（也可以说 I've had…）② I had it in Beijing in 2020. ③ I've seen this movie twice.
@diff: 「你吃过……吗？——没吃过。」——Have you ever…? — No, I haven't.
@d_cn: 问对方有没有过某种经历；回答「吃过」「没吃过」「从来没有」。
@d_en: Have you ever tried stinky tofu? — Yes, I have. / No, I haven't. / No, never.
@d_why: 中文回答时把动词再说一遍就行：「吃过」「没吃过」。英文的简短回答要用问句开头的那个 **have**：Yes, I have. / No, I haven't.（第一册 D10、D13 学过「问什么、答什么」的规律）。最常见的错是 ✗ Yes, I did. / ✗ No, I didn't.——人家问的是「有没有过」，不是「那一次做没做」。只答一句就停，聊天容易冷场：美国人回答后常补一句——说 Yes，就接着讲**什么时候、怎么样**（用过去式：I tried it in Changsha.
