@diff: 「不合身」——It doesn't fit.（不说 It isn't suitable.）
@d_cn: 衣服、鞋子的大小、长短、松紧不对：穿不上、太紧、太松、太短。
@d_en: It doesn't fit. / It's too tight. / It's a little loose. / It doesn't suit me.（不好看）
@d_why: 中文一个「不合适」管两件事：尺码不合适，或者款式、颜色不适合你。英文分得很清楚：**fit** 只说**尺寸**——大小、长短、松紧；**suit**（或 look good on）说的是**好不好看、配不配你**。很多人查词典把「合适」换成 suitable，说 ✗ It isn't suitable.，美国人会以为你在说「它不适合某个场合或用途」，比如不适合穿去面试。所以试完衣服，尺码问题先说 It doesn't fit.，再补一句具体哪里不对：It's too tight. / The sleeves are too short.
@d_when: 尺码问题 → doesn't fit / too tight / too loose；颜色、款式不衬你 → doesn't suit me / doesn't look good on me；场合不合适 → not suitable for…（不常用在衣服尺码上）。
@d_vs: **The jacket doesn't fit. It's too tight.** 外套不合身，太紧了。（尺寸）\n**This color doesn't suit me.** / **It doesn't look good on me.** 这个颜色不适合我。（好不好看）\n**Jeans aren't suitable for a job interview.** 牛仔裤不适合穿去面试。（场合）\n✗ The size isn't suitable for me.
@d_task: 用英文说：① 这双鞋不合脚，太紧了。② 这件衬衫的颜色不适合我。 | ① These shoes don't fit. They're too tight. ② The color of this shirt doesn't suit me.（或 This shirt doesn't look good on me.）
@diff: 「退货」「换货」——return / send it back；exchange it for…
@d_cn: 「退」= 把东西还回去、把钱拿回来；「换」= 把东西还回去，换一件别的。
@d_en: I'd like to return it. / Can I send it back? / Can I exchange it for a larger size?
@d_why: 中文「退货」「换货」是固定的名词说法；英文日常直接用动词，而且宾语要说出来：return **it** / return **this jacket**，不说 ✗ I want to return goods.（像外贸单据）。「换成……」一定要带 **for**：exchange A **for** B；中国学生最容易说 ✗ change it to a large。另外分清两个动作：网购寄回去常说 **send it back**；到店里当面退说 **return it**；return 只是「把东西退回去」，退「钱」是 refund（第一册学过）。
@d_when: 网上客服、门店、电话里处理不满意的商品：寄回 → send it back；当面退 → return it；换尺码、换颜色 → exchange it for…；要钱 → Can I get a refund?
@d_vs: **I'd like to return this.** 我想退货。\n**Can I send it back?** 我能寄回去吗？（网购）\n**Can I exchange it for a large?** 能换成 L 码吗？\n**Can I get a refund?** 能退款吗？\n✗ I want to change it to large.
@d_task: 网购的鞋太大，你想换小一号的。店员问 Do you want a refund?，你说不要退款，只想换。 | No, thanks. Can I exchange them for a smaller size?
@diff: 「试穿」——try it on
@d_cn: 买衣服、鞋之前先穿上看看合不合适。
@d_en: Can I try it on? / I tried it on at home. / Would you like to try it on?
@d_why: 中文有「试穿」「试戴」「试鞋」好几个说法；英文统一用 **try on**——try 是「试」，on 是「穿到身上」。只说 Can I try it? 意思不清楚，在店里可能被理解成「试用、试吃」。最容易错的是语序：宾语是 it / them 这种代词时，必须放在 try 和 on **中间**：try **it** on，✗ try on it；宾语是名词时两种都行：try on the jacket / try the jacket on。send it back、pick it up 也是同样的规则。
@d_when: 服装店、鞋店；店员常问 Would you like to try it on?；网购到货后说 I tried it on at home.
@d_vs: **Can I try it on?** 我能试穿吗？\n**Can I try on these shoes?** / **Can I try these shoes on?** 名词两种位置都行\n✗ Can I try on it? → ✓ Can I try it on?\n**Can I try it?** 只说 try，像「试用 / 试吃」
@d_task: 你在鞋店看中一双鞋，问店员能不能试穿；穿上以后告诉她「有点松」。 | Can I try them on? … They're a little loose.
@diff: 「缺货 / 没货了」——out of stock
