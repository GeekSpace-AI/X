@diff: used to do（以前常常）vs be used to doing（已经习惯）
@d_cn: 「以前常常……（现在不了）」和「（我已经）习惯……了」。
@d_en: I used to live with roommates.（以前）/ I'm used to living alone.（习惯了）/ I'm used to the heat.（习惯了）
@d_why: 这两个结构只差一个 **be**，意思却完全不同，是中国学生最容易混的一组。**used to + 动词原形**（Day 52）讲的是**过去**：以前常这样，现在不了。**be used to + 名词 / 动词-ing** 讲的是**现在的状态**：这件事对我来说已经不新鲜、不难受了，也就是「习惯了」。这里的 used 其实是形容词（熟悉的、适应的），to 是介词，所以后面跟名词或 -ing，不跟原形。判断只要看两个地方：①**前面有没有 am / is / are / was / get？** 没有 → 「以前」；有 → 「习惯」。②**to 后面是什么？** 原形动词（work、live）→ 「以前」；名词或 -ing（the heat、living）→ 「习惯」。最常见的两个错：漏掉 be（✗ I used to the heat.），和 to 后面接原形（✗ I'm used to live alone.）。
@d_when: 说「以前常……、现在不了」→ used to do；说「我已经习惯了 / 不觉得难了」→ be used to + 名词 / -ing。
@d_vs: **I used to live with roommates.** 我以前跟室友合租。（过去，现在不了）\n**I'm used to living alone.** 我习惯一个人住了。（现在的状态）\n**I'm used to the heat.** 这种热我习惯了。（to + 名词）\n✗ I'm used to live alone. ✗ I used to living alone. ✗ I used to the heat.
@d_task: 用英文说：① 我以前坐公交上班。② 我已经习惯走路上班了。 | ① I used to take the bus to work. ② I'm used to walking to work now.
@diff: 「慢慢习惯」——get used to（三兄弟一次分清）
@d_cn: 从不习惯到习惯的「过程」：慢慢习惯、适应了、会习惯的。
@d_en: It took me a few months to get used to it. / I'm getting used to it. / You'll get used to it.
@d_why: 中文「习惯了」既可以是状态（我习惯了），也可以是变化（我花了几个月才习惯）。英文把它拆成两个：**be used to** = 已经习惯（状态）；**get used to** = 变得习惯（过程）。所以「我花了几个月才习惯」一定用 get：It took me a few months to **get** used to it.；「我正在慢慢习惯」说 I'm **getting** used to it.；安慰刚来的人说 **You'll get used to it.**（口语常说 You're gonna get used to it.）。这样，三兄弟就清楚了：**used to do**（以前常……）、**be used to doing**（已经习惯）、**get used to doing**（渐渐习惯）——后两个的 to 后面都跟名词或 -ing。另外，「习惯」别想到 habit：habit 是「个人的习惯动作」（a bad habit，Day 52），不是「适应」。
@d_when: 说适应新环境用了多久、说自己正在适应、安慰新同事或新来的朋友。
@d_vs: **I'm used to it now.** 我现在习惯了。（状态）\n**It took me a few months to get used to it.** 我花了几个月才习惯。（过程）\n**I'm getting used to it.** 我在慢慢习惯。\n**You'll get used to it.** 你会习惯的。\n✗ I have a habit of the heat.
@d_task: Leo 说他还不会用深圳的公交 App，你安慰他：「别担心，你会慢慢习惯的。我花了两周才习惯。」 | Don't worry. You'll get used to it. It took me two weeks to get used to it.
@diff: 「我还不习惯」——I'm not used to it yet.
@d_cn: 到现在为止还没适应，可能以后会习惯。
